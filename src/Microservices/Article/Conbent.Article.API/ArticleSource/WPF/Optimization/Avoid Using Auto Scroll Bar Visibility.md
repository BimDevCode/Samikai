#ConbentDesktopProject 
#### Definition
Whenever possible, avoid using the [ScrollBarVisibility.Auto](https://learn.microsoft.com/en-us/dotnet/api/system.windows.controls.scrollbarvisibility#system-windows-controls-scrollbarvisibility-auto) value for the `HorizontalScrollBarVisibility` and `VerticalScrollBarVisibility` properties. These properties are defined for [RichTextBox](https://learn.microsoft.com/en-us/dotnet/api/system.windows.controls.richtextbox), [ScrollViewer](https://learn.microsoft.com/en-us/dotnet/api/system.windows.controls.scrollviewer), and [TextBox](https://learn.microsoft.com/en-us/dotnet/api/system.windows.controls.textbox) objects, and as an attached property for the [ListBox](https://learn.microsoft.com/en-us/dotnet/api/system.windows.controls.listbox) object. Instead, set [ScrollBarVisibility](https://learn.microsoft.com/en-us/dotnet/api/system.windows.controls.scrollbarvisibility) to [Disabled](https://learn.microsoft.com/en-us/dotnet/api/system.windows.controls.scrollbarvisibility#system-windows-controls-scrollbarvisibility-disabled), [Hidden](https://learn.microsoft.com/en-us/dotnet/api/system.windows.controls.scrollbarvisibility#system-windows-controls-scrollbarvisibility-hidden), or [Visible](https://learn.microsoft.com/en-us/dotnet/api/system.windows.controls.scrollbarvisibility#system-windows-controls-scrollbarvisibility-visible).

#### Summary
The [Auto](https://learn.microsoft.com/en-us/dotnet/api/system.windows.controls.scrollbarvisibility#system-windows-controls-scrollbarvisibility-auto) value is intended for cases when space is limited and scrollbars should only be displayed when necessary. For example, it may be useful to use this [ScrollBarVisibility](https://learn.microsoft.com/en-us/dotnet/api/system.windows.controls.scrollbarvisibility) value with a [ListBox](https://learn.microsoft.com/en-us/dotnet/api/system.windows.controls.listbox) of 30 items as opposed to a [TextBox](https://learn.microsoft.com/en-us/dotnet/api/system.windows.controls.textbox) with hundreds of lines of text.

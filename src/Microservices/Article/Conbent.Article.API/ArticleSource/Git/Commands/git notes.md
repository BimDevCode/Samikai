#ConbentWebProject 
#### Description
Git notes allow you to attach additional metadata to commits without altering the commit itself. This can be useful for adding annotations, reviews, or other contextual information to your commit history.

#### Cases
When you want to attach additional metadata or annotations to commits without altering the commit itself, such as adding reviews, comments, or other contextual information to your commit history.

#### Code
```
git notes
```

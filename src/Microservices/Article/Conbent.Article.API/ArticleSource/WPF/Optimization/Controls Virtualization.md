#ConbentDesktopProject 
#### Definition
By default, UI virtualization is enabled for the [ListView](https://learn.microsoft.com/en-us/dotnet/api/system.windows.controls.listview) and [ListBox](https://learn.microsoft.com/en-us/dotnet/api/system.windows.controls.listbox) controls when their list items are bound to data. [TreeView](https://learn.microsoft.com/en-us/dotnet/api/system.windows.controls.treeview) virtualization can be enabled by setting the [VirtualizingStackPanel.IsVirtualizing](https://learn.microsoft.com/en-us/dotnet/api/system.windows.controls.virtualizingstackpanel.isvirtualizing) attached property to `true`. If you want to enable UI virtualization for custom controls that derive from [ItemsControl](https://learn.microsoft.com/en-us/dotnet/api/system.windows.controls.itemscontrol) or existing item controls that use the [StackPanel](https://learn.microsoft.com/en-us/dotnet/api/system.windows.controls.stackpanel) class, such as [ComboBox](https://learn.microsoft.com/en-us/dotnet/api/system.windows.controls.combobox), you can set the [ItemsPanel](https://learn.microsoft.com/en-us/dotnet/api/system.windows.controls.itemscontrol.itemspanel) to [VirtualizingStackPanel](https://learn.microsoft.com/en-us/dotnet/api/system.windows.controls.virtualizingstackpanel) and set [IsVirtualizing](https://learn.microsoft.com/en-us/dotnet/api/system.windows.controls.virtualizingpanel.isvirtualizing) to `true`. Unfortunately, you can disable UI virtualization for these controls without realizing it. The following is a list of conditions that disable UI virtualization.

- Item containers are added directly to the [ItemsControl](https://learn.microsoft.com/en-us/dotnet/api/system.windows.controls.itemscontrol). For example, if an application explicitly adds [ListBoxItem](https://learn.microsoft.com/en-us/dotnet/api/system.windows.controls.listboxitem) objects to a [ListBox](https://learn.microsoft.com/en-us/dotnet/api/system.windows.controls.listbox), the [ListBox](https://learn.microsoft.com/en-us/dotnet/api/system.windows.controls.listbox) does not virtualize the [ListBoxItem](https://learn.microsoft.com/en-us/dotnet/api/system.windows.controls.listboxitem) objects.
    
- Item containers in the [ItemsControl](https://learn.microsoft.com/en-us/dotnet/api/system.windows.controls.itemscontrol) are of different types. For example, a [Menu](https://learn.microsoft.com/en-us/dotnet/api/system.windows.controls.menu) that uses [Separator](https://learn.microsoft.com/en-us/dotnet/api/system.windows.controls.separator) objects cannot implement item recycling because the [Menu](https://learn.microsoft.com/en-us/dotnet/api/system.windows.controls.menu) contains objects of type [Separator](https://learn.microsoft.com/en-us/dotnet/api/system.windows.controls.separator) and [MenuItem](https://learn.microsoft.com/en-us/dotnet/api/system.windows.controls.menuitem).
    
- Setting [CanContentScroll](https://learn.microsoft.com/en-us/dotnet/api/system.windows.controls.scrollviewer.cancontentscroll) to `false`.
    
- Setting [IsVirtualizing](https://learn.microsoft.com/en-us/dotnet/api/system.windows.controls.virtualizingstackpanel.isvirtualizing) to `false`.

Optimizing templates

The visual tree contains all the visual elements in an application. In addition to the objects directly created, it also contains objects due to template expansion. For example, when you create a [Button](https://learn.microsoft.com/en-us/dotnet/api/system.windows.controls.button), you also get [ClassicBorderDecorator](https://learn.microsoft.com/en-us/dotnet/api/microsoft.windows.themes.classicborderdecorator) and [ContentPresenter](https://learn.microsoft.com/en-us/dotnet/api/system.windows.controls.contentpresenter) objects in the visual tree. If you haven't optimized your control templates, you may be creating a lot of extra unnecessary objects in the visual tree. For more information on the visual tree, see [WPF Graphics Rendering Overview](https://learn.microsoft.com/en-us/dotnet/desktop/wpf/graphics-multimedia/wpf-graphics-rendering-overview?view=netframeworkdesktop-4.8).

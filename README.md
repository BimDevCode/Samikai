# SAMIKAI
## Summary 
### Articles Blog Application
Currently under development, this application serves as a blog featuring original, insightful articles on software development that were have curated throughout my career.

## Technology Stack:
**Frontend**: Developed with Angular, providing a dynamic and responsive user interface.
**Backend**: Built using .NET, ensuring robust and scalable application architecture.
**Database**: Utilizes PostgreSQL for efficient and reliable data storage.

### Features and Infrastructure:
- **Identity API** for secure authentication and user management.
- **RabbitMQ** for message queuing and asynchronous communication.
- **Telemetry** for application monitoring and performance insights.
- **Gateway** Approach for streamlined API routing and centralized communication.
- **Docker** for containerization, enabling consistency across development and production environments.
- **Azure CLI** for seamless cloud integration and deployment.

This project reflects modern development practices and showcases a full-stack implementation with cutting-edge tools and frameworks.
